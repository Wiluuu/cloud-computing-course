# Mission Reflection: Cloud Infrastructure Blueprint

### 1. Which cloud infrastructure component do you think is the most important? Why?
While all components work together, **Networking** serves as the most critical backbone of cloud infrastructure. Without networking, compute instances remain isolated, storage cannot be accessed by applications, and users cannot reach services.

### 2. How does Linux support cloud computing?
Linux serves as the foundational operating system powering most cloud infrastructure worldwide. Its lightweight design, stability, security model, and command-line automation capabilities make it ideal for cloud instances and containers.

### 3. Why is technical documentation important before deploying infrastructure?
Documenting system blueprints before deployment prevents costly design errors, security oversights, and unnecessary spending. Clear documentation aligns engineering teams and speeds up future troubleshooting.

### 4. What new skills did you learn during this laboratory activity?
I strengthened my ability to audit Linux system metrics using CLI commands (`lscpu`, `free`, `df`), compare equivalent services across major cloud providers (AWS, Azure, GCP), design cloud architecture diagrams, and present technical findings using Markdown.

### 5. How has your GitHub portfolio improved after completing this mission?
Completing this mission transforms my repository into a structured cloud engineering portfolio, demonstrating system investigation, architecture design, and technical reporting.
