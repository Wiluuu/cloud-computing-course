# Laboratory Activity 02: Build the Cloud Infrastructure Blueprint

## Mission Overview
This laboratory assignment focuses on analyzing fundamental cloud infrastructure components. Working as a cloud engineer for CloudNova Technologies, this mission investigates compute, storage, networking, and identity architectures through Linux environment inspection, provider comparison, and cloud architecture modeling.

## Mission Objectives
* Investigate Linux environment hardware and software metrics.
* Distinguish between compute, storage, networking, and identity resources.
* Compare AWS, Azure, and GCP core offerings.
* Produce structured technical documentation using Markdown.
* Design a cloud system architecture blueprint.

## Cloud Infrastructure Components Analyzed
* **Compute:** CPU allocation, RAM execution space.
* **Storage:** Persistent block storage mounts and volume sizes.
* **Networking:** System IP routing and network virtual interfaces.
* **Identity:** Linux root user access and role permissions.
