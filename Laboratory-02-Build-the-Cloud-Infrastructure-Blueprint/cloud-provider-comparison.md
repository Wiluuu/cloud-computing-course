## Guided Analysis

### 1. Which cloud provider offers the broadest range of services?
**AWS (Amazon Web Services)** offers the broadest and most mature portfolio of cloud services globally. As a pioneer in public cloud infrastructure, AWS maintains an extensive catalog covering compute, storage, edge computing, serverless, and enterprise capabilities.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?
**Microsoft Azure** is recommended for organizations using Microsoft software ecosystems. Azure integrates natively with Microsoft Entra ID, Windows Server, Office 365, and SQL Server.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
**Google Cloud Platform (GCP)** is widely recognized for AI/ML and container orchestration, having originally created Kubernetes and TensorFlow. GCP provides managed environments like Google Kubernetes Engine (GKE) and Vertex AI.

### 4. What similarities did you observe among the three cloud providers?
All three providers abstract physical hardware into compute, storage, and networking. They enforce strict security via dedicated Identity and Access Management (IAM) systems and use a pay-as-you-go pricing model.
