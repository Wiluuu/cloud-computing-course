# Laboratory-06-Cloud-Deployment-Engineer

## Mission Overview
Transitioned from manual container commands to Infrastructure as Code (IaC) by deploying a multi-tier enterprise private cloud storage solution (Nextcloud and MariaDB) using Docker Compose.

## Objectives
* Explain multi-tier application architectures[cite: 1].
* Create and configure `docker-compose.yml` blueprints[cite: 1].
* Deploy multi-container application stacks using Docker Compose[cite: 1].
* Document IaC workflows via Markdown and GitHub[cite: 1].

## Commands Executed
* `mkdir nextcloud-deployment`
* `cd nextcloud-deployment`
* `nano docker-compose.yml`
* `docker-compose up -d`
* `docker-compose ps`
* `docker-compose down`

## Skills Learned
* Multi-tier architecture design and container networking[cite: 1].
* Infrastructure as Code implementation with YAML[cite: 1].
* Managing container stacks with Docker Compose[cite: 1].
